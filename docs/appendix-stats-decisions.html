1 Which Statistical Test Should I Use?

Here is a quick overview of the most common statistical tests and when to use them. The following tables summarize the questions you might ask, the type of data you have, and the appropriate statistical test to use.

1.1 Decision Table by Questions and Data Types

Question Categorical Continuous Refer to
Is a variable different from a baseline? Chi-Square Goodness-of-Fit Test One-sample z-test or One-sample t-test Table 1
Do groups/conditions differ? N/A t-test or ANOVA Table 2
Are two variables related? Chi-Square Test of Independence Pearson Correlation Table 3
Can scores be predicted? N/A Simple or Multiple Linear Regression Table 4
